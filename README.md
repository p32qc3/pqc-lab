# PQC.LAB

潘泉承的赛博朋克风格个人项目网站，展示嵌入式系统、AI 识别、数据建模、竞赛项目与一个原创 Canvas 小游戏。

## 内容

- 公开展示姓名、上海理工大学、项目经历、获奖记录与邮箱 `panquancheng2006@163.com`
- 第一个嵌入式芯片项目链接到 GitHub 项目 `Edgi-Talk`
- 页面背景包含轻量电路交互效果，不接入统计、跟踪或后台服务
- 首次访问会播放约 3 秒的“芯片唤醒”动画，可跳过；当天再次访问会直接进入主页
- 顶部导航始终可用，手机导航采用更大的点击区域；页尾提供邮件联系与返回顶部入口
- 正文不依赖入场动画显示；开场支持 Escape 跳过及键盘操作
- 小游戏支持跳跃、蹲下、暂停，以及废弃芯片、电子废料、飞线、激光线等障碍；地面障碍必须跳跃，飞线和激光必须蹲下

## 游戏操作

- 电脑：W 跳跃，按住 S 蹲下；空格键和方向键仍可使用
- 手机：点击“跳跃”，按住“蹲下”并在需要起身时松开
- 暂停：使用游戏下方的暂停按钮
- 未开始游戏时，空格和方向键保留网页滚动功能；聚焦按钮后可用键盘操作
- 浏览器禁用本地存储时仍可游玩，本次访问的最高分暂存于内存

## 本地查看

```text
npm run serve
```

## 检查

```text
npm test
```

浏览器检查使用本机 Playwright 和 Chromium/Edge；设置 `PLAYWRIGHT_MODULE_URL` 和 `PLAYWRIGHT_CHROMIUM_PATH` 后运行：

```text
npm run test:browser
node tests/usability-browser.mjs
node tests/game-stability-browser.mjs
```
