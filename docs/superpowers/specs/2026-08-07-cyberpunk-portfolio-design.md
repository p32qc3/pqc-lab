# 赛博朋克个人作品网站设计说明

## 目标

制作一个任何人都能通过公开链接访问的单页个人作品网站。网站突出做过的项目、承担的工作、技术能力和获奖结果，并加入一个可直接游玩的原创躲避障碍小游戏。

## 视觉方向

- 采用已确认的“霓虹都市”赛博朋克风格。
- 主色为深黑紫，辅色为青蓝与洋红霓虹。
- 使用网格、扫描线、状态面板和像素元素营造氛围。
- 正文保持高对比度和清晰层级，确保风格不影响阅读。
- 不使用人物照片或其他人物形象。

## 页面结构

1. 顶部导航：项目、小游戏、能力、奖项。
2. 首屏：公开定位与一句核心介绍，不出现个人身份信息。
3. 代表项目：环境音识别、自动泊车模型拓展、青年就业与老龄化数据建模。
4. 霓虹跑酷小游戏：原创机械小兽躲避故障芯片和能量障碍。
5. 技术能力：嵌入式系统、算法编程、数据建模和 AI 工程工具。
6. 项目与获奖时间线：展示竞赛名称、承担角色、工作内容和奖项。
7. 页尾：隐私说明，不提供联系入口。

## 隐私规则

- 不展示完整姓名、照片、GPA、学校、院系、电话、邮箱和所在地。
- 不接入访问统计、广告、第三方跟踪脚本或需要提交个人信息的表单。
- 公开内容仅限项目、工作内容、技术能力、竞赛角色和获奖结果。
- 网站标识统一使用“PQC.LAB”。

## 小游戏规则

- 玩法为横向自动奔跑和单键跳跃，灵感来自离线躲避障碍游戏，但角色和画面均为原创。
- 电脑端支持空格键和向上方向键；移动端支持点击或触摸游戏区域。
- 障碍物速度随分数逐步提高，碰撞后显示本局得分和重新开始按钮。
- 最高分仅保存在访问者自己的浏览器中；如果浏览器不允许保存，游戏仍可正常运行。
- 游戏可暂停，并尊重系统的“减少动态效果”设置。

## 实现方式

- 使用静态 HTML、CSS 和 JavaScript，不依赖服务器或数据库。
- 小游戏使用 Canvas 绘制，页面其他部分使用普通网页元素。
- 所有资源随网站一起发布，不依赖外部字体、图片或接口。
- 网站将发布到公开的 GitHub Pages，生成可分享的访问链接。

## 适配与检查

- 支持主流电脑浏览器和手机浏览器。
- 检查桌面与手机布局、导航、文字可读性、按钮操作和游戏碰撞。
- 检查键盘、触摸操作、重新开始、最高分保存和页面刷新后的行为。
- 发布前扫描网站文件，确认不包含已要求隐藏的个人信息。

## 完成标准

- 公开链接可以在未登录状态下打开。
- 页面风格与已确认的霓虹都市预览一致。
- 项目和获奖信息完整且无隐私字段。
- 小游戏在电脑和手机上均可游玩。
- 本地检查和公开页面检查均通过。
